# Verto — Android-клиент

Учебное приложение электронной платёжной системы на Kotlin и Jetpack Compose.
Регистрация и вход, баланс, демонстрационное пополнение, поиск получателя, переводы и история операций.
Клиент обращается к собственному [Ktor-серверу](https://github.com/danielmirrox/verto-server); Firebase не используется.

## Запуск

1. Клонировать проект в каталог с ASCII-путём, например `C:/dev/verto-client`.
2. Установить JDK 21 и Android SDK с платформой/инструментами, указанными в Gradle-конфигурации (проверялся SDK 36.1).
3. Задать `ANDROID_HOME` либо путь `sdk.dir` в локальном `local.properties` — этот файл не добавлять в Git.
4. Поднять PostgreSQL и сервер по [его README](https://github.com/danielmirrox/verto-server#readme).
5. Собрать и проверить клиент:

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest --no-daemon --max-workers=1
```

На Linux/macOS: `./gradlew assembleDebug testDebugUnitTest --no-daemon --max-workers=1`.
APK появится в `app/build/outputs/apk/debug/`. Запустить на Android-эмуляторе; адрес API задан в `ApiConfig.kt`: `http://10.0.2.2:8080/api/v1/`.
Для другого стенда адрес необходимо изменить и пересобрать клиент. Для перевода зарегистрировать два учебных аккаунта.

## Устройство клиента

Слои `domain` / `data` / `presentation`, ViewModel/StateFlow, Ktor Client, SharedPreferences для истории выбранных получателей.
История хранит до 10 уникальных получателей. Сессия живёт в памяти процесса: после завершения процесса нужен повторный вход.
Выход очищает экран и сессию; постоянную историю удаляет отдельная кнопка.

## Границы проекта

Учебный прототип: суммы — целые рубли, пополнение демонстрационное, реальные деньги и платёжные провайдеры не подключены.
Локальный HTTP; для внешней сети нужны HTTPS и дополнительная проверка безопасности.
Серверная идемпотентность и нагрузочные испытания не реализованы. Работа на всех физических устройствах не проверялась.

## Проверки

На принятой версии от **5 октября 2026** прошли 13 серверных и 6 клиентских JVM-тестов, 18 HTTP-проверок с PostgreSQL и 15 пользовательских сценариев на эмуляторе Android API 35.
Это исторические результаты локальной проверки, а не запущенный GitHub CI. Повторный запуск выполняется командами выше.
Протоколы, APK, видео, подписанный отчёт и прочие материалы курсовой хранятся отдельно и в этот репозиторий не включены.
